TIC-TAC-TOE

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

📌 About the Project

This is a two-player Tic-Tac-Toe game where players take turns marking X and O on a 3×3 game board. The game automatically detects the winner or a draw.

✨ Features
1. Two-player gameplay
2. X and ⭕ O turns
3. Automatic winner detection
4. Draw detection
5. New Game / Reset functionality
6. Simple and responsive user interface
   
🛠️ Technologies Used
1. HTML5
2. CSS3
3. JavaScript
